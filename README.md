**Tool-guided repair for LLM-generated C** · first author, [arXiv:2607.21641](https://arxiv.org/abs/2607.21641) · 2nd Place, Engineering, Penn State Undergraduate Exhibition 2026\
A repair loop that feeds GCC and CodeQL findings back to the model, guided by a growing library of past fixes, with KLEE symbolic execution as the final check. Across 5,000 C tasks it cut CodeLlama 7B's CodeQL errors from 15,088 to 2,463 (83.7% fewer).
